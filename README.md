# SCP Foundation Recruitment Portal — Fictional Fan Site

A static, GitHub Pages-friendly prank/demo website. It includes:
- Homepage
- Sign up and login using browser `localStorage`
- Recruitment application form
- Application status page
- Automatic simulated hiring exactly 30 seconds after submission
- Responsive mobile layout

## GitHub Pages setup
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose your main branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish it.

### Important
This is a fictional fan/prank website. The login system is **not secure authentication**: passwords are stored in browser localStorage. Do not use real passwords or real personal information. No real applications are sent anywhere; everything happens locally in the browser.
